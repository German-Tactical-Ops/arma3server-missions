# arma3server-missions

Contains Arma 3 multiplayer mission files (`.pbo`) for the `arma3server-container`.

## Overview

This directory contains missions for training, operations, and Zeus events across various terrains:

- **Dynamic Recon Ops (ACE):** Randomized reconnaissance operations (Altis, Livonia, Takistan, Tanoa).
- **GTO Zeus Missions:** Zeus templates configured for various maps (Altis, Enoch, Malden, Stratis, Tanoa, VR, Lybor, Takistan).
- **KP Liberation:** CTI persistent warfare missions (Enoch, Tanoa).
- **Training Missions:** Dedicated training scenarios (e.g. *GTO Training Ground*, *Medic Training*).
- **Custom Operations:** Community operations and scenarios (e.g. *Operation Ice Mountains*).

## Usage

These mission files are intended to be mounted or copied into the server container's `mpmissions/` folder (`/home/arma3server/server/mpmissions`).
